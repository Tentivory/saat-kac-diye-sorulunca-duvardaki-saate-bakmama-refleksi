# Saat Kaç Diye Sorulunca Duvardaki Saate Bakmama Refleksi Enstitüsü

**Kuruluş yılı:** 5 Eylül 2026, saat tam olarak *telefonu çıkardıktan sonra*.

Bu yazılım, uygarlığın en küçük ve en utanç verici sapmalarından birini bilimsel ciddiyetle inceler:

> Birisi “saat kaç?” diye sorduğunda, gözünün önünde duran duvar saatine bakmak yerine cep telefonunu çıkarmak.

Enstitü bu hareketi şunlardan biri olarak kayda geçer:

- milli zaman egemenliği sapması
- duvar protokolü ihlali
- cep ekranına bağımlılık kriz masası vakası
- “duvar saati de bir vatandaştır” maddesinin çiğnenmesi

## Neden bu kadar ciddi?

Çünkü değil. Ama resmi görünmesi lazım. Resmi görünmeyen şeyler çalışmaz. Bu yazılım çalışır.

Duvar saati oradadır. Piller takılıdır. Akrep ilerler. Yelkovan ilerler. Vatandaş yine de cebine uzanır. Enstitü bu uzanmayı ölçer, puanlar, raporlar ve utandırır.

## Kurulum

```bash
python3 enstitu.py
```

Bağımlılık yoktur. Sadece Python 3. Standart kütüphane yeter. Çünkü utancın kendisi yeterince ağırdır.

## Kullanım

Program açılınca size “Saat kaç?” diye sorulur. Siz:

- `duvar` yazarsanız Enstitü sizi alkışlar (nadir vakadır)
- `telefon` yazarsanız resmi sapma tutanağı düzenlenir
- `bilek` yazarsanız kol saati diplomatik muafiyet talebi açılır
- `bilmiyorum` yazarsanız zamanın kendisi şikayet edilir

Ardından katsayılar hesaplanır:

- **Refleks Endeksi** (0–100)
- **Duvar İhaneti Puanı**
- **Ekran Bağımlılık Katsayısı**
- **Utanç Desibeli**

Hepsi uydurmadır. Hepsi çalışır.

## Bilimsel dayanak (yok)

Enstitü şu varsayımlara dayanır:

1. Duvar saati bakıldığında kırılmaz.
2. Telefon çıkarıldığında bildirim de görülür; bu “bonus sapma”dır.
3. “Bir saniye bakayım” cümlesi resmi itiraftır.
4. Duvardaki saatin üç dakika ileri olması milli affetme kapsamı dışındadır.

## Sık sorulan sorular

**Bu gerçekten çalışıyor mu?**  
Evet. Utanç üretir, rapor basar, çıkar.

**Neden Türkçe?**  
Çünkü “saat kaç?” Türkçe sorulur. Cevap cepte aranır.

**Patates var mı?**  
Yok. Yasaktır. Enstitü patates dosyası açmaz.

**Siyasi midir?**  
Hayır. Sadece duvar saati siyasidir; bakmayan bakmış sayılmaz.
